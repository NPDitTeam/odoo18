# NPD Head Office Branch Mapping (`npd_head_office_branch`)

กำหนดว่า "สาขาไหนบ้าง" ที่ต้องออกเอกสารในนาม **สำนักงานใหญ่**
แล้วให้ระบบเติมฟิลด์ใหม่ **สาขาสำนักงานใหญ่** ให้อัตโนมัติในฟอร์ม 3 เมนู

| เมนู | โมเดล | ขอบเขต |
|---|---|---|
| บิล (ผู้ขาย) | `account.move` | `move_type` = `in_invoice` / `in_refund` |
| Avance Clear | `account.advance.clear` | ทุกรายการ |
| การรับ | `account.voucher` | **เฉพาะ `check_type_show_selection = False`** |

## วิธีใช้

1. ไปที่ **การออกใบแจ้งหนี้ > การกำหนดค่า > สาขาสำนักงานใหญ่ > กำหนดค่าสาขา**
   ระบบจะเด้ง popup ขึ้นมา
2. เลือก **สาขาสำนักงานใหญ่** (ค่าที่จะเด้งให้อัตโนมัติ)
3. ในแท็บ **บิลผู้ขาย / Avance Clear / การรับ** ใส่รายชื่อสาขาที่ระบุ
   เช่น `อยุธยา`, `ชะอำ`, `ภูเก็ต`
4. กด **บันทึก** — เอกสารที่บันทึกใหม่ตั้งแต่นี้จะได้ค่าทันที
   หรือกด **บันทึก + ปรับใช้ย้อนหลัง** ถ้าต้องการให้เอกสารเก่าได้ค่าด้วย

ผลลัพธ์: ในฟอร์มของทั้ง 3 เมนู เมื่อเลือก `Branch` เป็น อยุธยา / ชะอำ / ภูเก็ต
ฟิลด์ **สาขาสำนักงานใหญ่** จะเด้งเป็น `สำนักงานใหญ่` ให้เองทันที

## สาขาที่ไม่ได้ระบุไว้

ควบคุมด้วยตัวเลือก **ถ้าไม่ตรงรายการ ให้ใช้สาขาของเอกสารเอง**

* ติ๊กไว้ (ค่าเริ่มต้น) — ฟิลด์ใหม่จะแสดงสาขาของเอกสารเอง
  ทำให้ฟิลด์นี้ใช้เป็น "สาขาที่ใช้ออกเอกสารจริง" ได้ทุกใบ
* ไม่ติ๊ก — ฟิลด์ใหม่จะว่างไว้ เห็นชัดว่าใบไหนเข้าเงื่อนไขบ้าง

## แก้ไขสาขาสำนักงานใหญ่เอง (ทั้ง 3 เมนู)

* ตั้งค่า > ผู้ใช้ > แท็บ **สิทธิ์การเข้าถึง** > ติ๊ก
  **แก้ไขสาขาสำนักงานใหญ่เองได้** (ค่าเริ่มต้น ไม่ติ๊ก)
* ติ๊กแล้ว ฟิลด์ **สาขาสำนักงานใหญ่** ในฟอร์ม บิลผู้ขาย / Avance Clear / การรับ
  จะแก้ทับค่าที่ระบบเติมให้ได้ ผู้ใช้ที่ไม่ติ๊กเห็นเป็นอ่านอย่างเดียว
  (ฝั่งเซิร์ฟเวอร์ตัดค่าที่ส่งมาทิ้งด้วย รวมถึงโค้ดที่รันด้วย superuser)
* ตรรกะอยู่ใน mixin `npd.head.office.branch.edit.mixin`
* ถ้าเปลี่ยน **Branch** ภายหลัง ระบบจะคำนวณค่าให้ใหม่ (แก้ทับอีกรอบได้)
* ใบที่ค่าต่างจากที่ระบบให้ จะถูกติ๊ก `head_office_branch_manual`
  และปุ่ม **ปรับใช้ย้อนหลัง** จะข้ามใบนั้น ไม่คำนวณทับ

## เคสย้อนหลัง

* ปุ่ม **บันทึก + ปรับใช้ย้อนหลัง** จะไล่คำนวณเอกสารเก่าทั้งหมดของบริษัทนั้นใหม่
  (ทำงานผ่าน `_write` จึงปรับเอกสารที่ลงบัญชีแล้วได้ โดยไม่แตะตัวเลขทางบัญชี)
* ทุกครั้งที่กด ระบบจะเก็บประวัติไว้ที่
  **การกำหนดค่า > สาขาสำนักงานใหญ่ > ประวัติการปรับใช้ย้อนหลัง**
  โดยเก็บ: ใครกด เมื่อไหร่ ตั้งค่าอะไรไว้ ตรวจกี่ใบ เปลี่ยนกี่ใบ
  พร้อมรายการเอกสารที่ถูกเปลี่ยน (ค่าเดิม → ค่าใหม่) กดเปิดเอกสารตรงจากรายการได้

> ทุกครั้งที่แก้รายชื่อสาขาในหน้ากำหนดค่า ต้องกด **ปรับใช้ย้อนหลัง**
> ถ้าอยากให้เอกสารเก่าเปลี่ยนตามด้วย (การแก้ค่ากำหนดค่าเฉย ๆ
> ไม่ทำให้ Odoo คำนวณเอกสารเก่าใหม่เอง)

## หมายเหตุทางเทคนิค

* ฟิลด์ใหม่ชื่อ `head_office_branch_id` เหมือนกันทั้ง 3 โมเดล
  เป็น computed + `store=True` + `readonly=False` คำนวณจาก `branch_id`
  (แก้ได้เฉพาะผู้ใช้ที่มีสิทธิ์ ดูหัวข้อด้านบน)
* การกำหนดค่าแยกตามบริษัท (`res.company`) หนึ่งบริษัทหนึ่งชุด
* สิทธิ์การแก้ไข: `account.group_account_manager`

## ติดตั้ง

```
Apps > Update Apps List > ค้นหา "NPD Head Office Branch Mapping" > Install
```

หรือจาก command line:

```
odoo-bin -c odoo.conf -d <database> -u npd_head_office_branch --stop-after-init
```
